About

운영 품질을 구조로 개선하는 Backend Engineer

문제를 빠르게 고치는 것보다, 같은 문제가 반복되지 않도록 시스템을 재설계하는 데 집중합니다.

Problem Solving Frame

Observe -> Redesign -> Guardrail

진단부터 재발 방지까지 이어지는 일관된 백엔드 개선 사이클

Observe

메트릭/로그를 우선 확인해 문제를 숫자로 정의하고, 영향 범위를 가시화합니다.

  • 병목 시점/구간 계측
  • 서비스 영향 범위 분석
  • 정량화된 기준선 수립

Redesign

운영 구조의 병목 지점을 아키텍처/플로우 관점에서 재구성합니다.

  • 메시징 토폴로지 전환
  • 인증 플로우 표준화
  • 조회 경로 최적화

Guardrail

개선 이후 안정적으로 운영되도록 관측 지표와 자동화를 함께 설계합니다.

  • 운영 자동화 및 알림 체계 정비
  • 무중단 전환 전략 적용
  • 팀 내 운영 기준 문서화

Strength

핵심 역량

실시간 메시징 운영 최적화

AMQ/MQTT 기반 시스템에서 병목을 관측하고 운영 안정성을 개선합니다.

인증 서버 설계/운영

OAuth 2.0/OIDC 기반 인증 서버를 구축하고 서비스 요구에 맞게 커스텀합니다.

백오피스 운영 효율화

비용, 인증 품질, 조회 성능의 균형을 맞춘 운영 개선을 수행합니다.

운영 자동화

반복 작업을 제거하고 장애 대응 속도를 높이는 자동화 체계를 구축합니다.

Company 비로보틱스 · Period 2025.04 ~ 2025.08 · Role Backend Engineer

문제

피크 타임에 브로커 CPU가 90% 이상 유지되고 호출벨 처리 경로의 고정 5초 대기로 서비스 응답성이 저하됐습니다. 또한 Spring WebFlux 기반 호출벨 서버의 운영 관제와 장애 대응 체계가 필요했습니다.

접근

  • MQ 및 서버 System Metric을 상시 모니터링하고 병목 패턴을 분석했습니다.
  • 브로커 구조를 Mesh Topology에서 Concentrator Topology로 전환했습니다.
  • Heartbeat transition(주기 3초) 기반 즉시 처리 Handler를 구현해 호출벨 고정 대기를 제거했습니다.
  • Spring WebFlux 기반 비동기 호출벨 서버 운영 표준(관제/장애 대응)을 정립해 운영 안정성을 강화했습니다.

성과

  • 로봇 커넥션 수용량 1.5배 증가
  • 피크 타임 CPU 사용률 30% 개선(90%+ 구간 완화)
  • 호출벨 기본 지연 5초 제거(즉시 처리)

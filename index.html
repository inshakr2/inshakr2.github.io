System Thinking

백엔드 문제 해결 프레임

재발 방지까지 포함해 운영 시스템을 개선하는 방법론입니다.

01

Observe

메트릭, 로그, 트레이스를 우선 확인해 문제를 숫자로 정의합니다.

  • 병목 구간 식별
  • 영향 범위 정량화
  • 운영 지표 기준선 설정
02

Redesign

단순 패치보다 토폴로지/플로우 관점에서 구조를 재설계합니다.

  • 메시징 토폴로지 개선
  • 인증 플로우 표준화
  • 검색/조회 경로 재구성
03

Guardrail

재발을 막기 위해 운영 자동화와 관측 포인트를 함께 남깁니다.

  • 모니터링 자동화
  • 무중단 전환 전략
  • 운영 기준 문서화

Now / Next

현재 집중 영역과 다음 확장

운영 백엔드 역량을 기반으로 확장하고 있는 기술 축입니다.

Now

운영 중인 서비스에서 메시징/인증/백오피스 성능을 개선하고, 인프라 운영 안정성까지 함께 고도화하고 있습니다.

Java Spring Boot Spring WebFlux AWS Docker Kubernetes Jenkins AMQ/MQTT OAuth 2.0 / OIDC Redis OpenSearch

Next

확장 가능한 플랫폼을 위한 아키텍처 설계 역량을 강화하고, 구현 속도를 높이는 실전형 개발 방식을 실험 중입니다.

  • 실시간 메시징 운영 표준화
  • 아키텍처 설계 분야 심화(도메인 분리, 경계 정의, 확장 전략)
  • 인증 서버 고가용성 패턴 강화
  • 바이브 코딩 기반 고속 프로토타이핑과 검증 루프 최적화
